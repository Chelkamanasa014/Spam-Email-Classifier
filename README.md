# Spam-Email-Classifier
A machine learning project to classify emails as spam or not spam using python
Spam Email Classifier

Project Description

The Spam Email Classifier is a machine learning project developed using Python. It classifies email messages into two categories: Spam and Not Spam.

Technologies Used

- Python
- Scikit-learn
- TF-IDF Vectorization
- Naive Bayes Algorithm

Features

- Trains a machine learning model using sample email messages.
- Predicts whether an email is spam or not spam.
- Allows users to enter their own email messages for classification.

How to Run

1. Install Python.

2. Install the required library:
   
   "python -m pip install scikit-learn"

3. Run the program:
   
   "python spam_classifier.py"
